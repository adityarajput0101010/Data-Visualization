# 📊 Data Visualization Dashboard (Tableau)

This repository contains an interactive data visualization dashboard built using Tableau. The project focuses on analyzing and presenting insights from a dataset (e.g., Netflix Movies & TV Shows) in a clear and visually appealing way.

---

## 🚀 Features

* Interactive dashboard with filters
* Top categories/genres analysis
* Ratings distribution visualization
* Movies vs TV Shows comparison
* Year-wise content trends
